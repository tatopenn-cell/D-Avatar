D-Avatar turns a stream of face landmarks into stable avatar parameters and sends them over OSC/VMC, built on [dense_armor](https://github.com/tatopenn-cell/Dense-Armor).

Install: `pip install "git+https://github.com/tatopenn-cell/D-Avatar.git#egg=d-avatar[osc]"`

Guide: [docs/index.md](docs/index.md)
